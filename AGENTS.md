# Repository instructions

Use **YGO Work** for this repository. Its canonical source and build tooling live in [ygo-work](https://github.com/SeyTi01/work-plugins/tree/main/plugins/ygo-work). The installed ChatGPT plugin is a standalone build of that source.

If the installed plugin is unavailable, read the matching skill from the private source repository through authenticated GitHub access or a local `work-plugins` checkout. Do not recreate plugin instructions in this repository. If neither source is accessible, report the access limitation.
